# Rules of borrowing

Как слово из человеческого языка становится офидским. Буквы справа — стандартная
латиница (latin-1) из [[Transliteration]]; `o` [ɔ] и `u` [ɯ] есть в [[Inventory]]
именно ради заимствований. Сами заимствованные слова собираются в [[Borrowings]].

## From Russian

1. Only the stem is borrowed.
2. Out of several consecutive consonants, the last is used, others drop (e.g. -стр- → l)
3. The word is borrowed in sg. / infinitive form. 

| Русский        | Офидский |
| -------------- | -------- |
| ф, в, п, б, м  | → t      |
| д, т, с, з, ц  | → s      |
| дь, ть, сь, зь | → c      |
| ш, ж           | → ș      |
| щ, жь          | → ś      |
| хь, кь, гь, й  | → j      |
| х, к, г        | → x      |
| л, н, р        | → l      |
| ль, нь, рь     | → ļ      |
| а | → а |
| э | → e |
| и | → i |
| о | → o |
| у | → u |
| ы | → u |
