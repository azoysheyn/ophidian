I. When used with a numeral the noun stays in its singular form.

> *seciși serixa seseśe [^1] selata* — three big green serpents

Leipzig gloss (`CL1` = noun class 1):

```
se-ciși      se-rixa    se-seśe   se-lata
CL1-serpent  CL1-green  CL1-big   CL1-three
```

Every word carries the class prefix [[se-]]. Class 1 is singular, so number gets no separate gloss.
The noun gets the meaning of the whole word (*serpent*), not of the root [[-ciși-]] (*living being*).

[^1]: alternatively: sseeśe
