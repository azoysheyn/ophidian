# Questions

## Общий вопрос — частица *śi*

Частица [[śi]] стоит в конце общего вопроса (да/нет).

Схема: *X глагол Y śi?* — X делает Y?

Примеры:
- *seciși seseșesse teja śi?* — змея ест яйца?
- *șe sire śi?* — это камень? (в Sandbox: *șe sire ļi?*)

Решено 14 ноя 2026. В Sandbox есть варианты частицы *ļi*, *sji/lji* — это ранние формы.

Ответ: [[hee]] «да» или [[ssaa]] «нет».

## Вопросительные слова — *ssi'i* + существительное

Вопросительное слово строится по одной модели:
[[ssi'i]] «что, кто, какой» + существительное.

Пример: *ssi'i gaśi* — какое место → где.

Одно *ssi'i* без существительного значит «кто» или «что».

### Список на перевод

Для каждого вопроса нужно существительное. Часть из них уже есть в словаре.

| Вопрос | Модель | Существительное | Есть в словаре |
| --- | --- | --- | --- |
| кто, что | *ssi'i* | — | да |
| какой | *ssi'i* + сущ. | любое | да |
| где | *ssi'i gaśi* | место | да: [[gaśi]] |
| куда | *xaa ssi'i gaśi* | место | да, но см. «откуда и куда» в [[Participants]] |
| откуда | ? | место | нет способа сказать «из» |
| когда | *ssi'i* + «время» | время | **нет** |
| сколько | *ssi'i* + «число» | число, количество | **нет** |
| почему | *ssi'i* + «причина» | причина | **нет** (есть только союз [[śega]] «потому что») |
| как | *ssi'i* + «способ» | способ, путь | **нет** |
| чей | *ssi'i-ji* | — | да: [[-ji]] |

Нужно перевести: **время, число, причина, способ.**
